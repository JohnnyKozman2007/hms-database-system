# Final Report Drafts & Contributions

This folder stores the report drafts and sections required by Section 19 of the briefing sheet.

## Coursework Report Structure (Word / PDF)

1. **Title Page**: Module Code (4FTC2063), Module Title (Data Modeling for DB), Module Leader (Mohammed Abd AlAleem), Team Members & Student IDs.
2. **1. Introduction**: Purpose of the Hospital Management System (HMS) database project.
3. **2. System Description**: Overview of the 16 entities and functional areas (Staff, Clinical, Pharmacy, Billing).
4. **3. Project Objectives**: The 12 objectives listed in Section 2 of the brief.
5. **4. Requirements**: Business rules, constraints, integrity rules.
6. **5. Entity Descriptions**: Detailed description of each of the 16 entities, their attributes, and their purpose.
7. **6. ERD (Entity Relationship Diagram)**: Final integrated ERD showing all 16 entities and cardinalities.
8. **7. Relational Schema**: Normalized relational schema with primary and foreign keys highlighted.
9. **8. Normalization (1NF, 2NF, 3NF)**: Detailed justification showing how the database complies with 3NF.
10. **9. Database Implementation**: Overview of Oracle DDL scripts, constraints, data types, and row count metrics.
11. **10. SQL Queries**: 35 queries total (7 queries per student: 2 Easy, 3 Medium, 2 Hard), including SQL code, explanation, and query output tables/screenshots.
12. **11. Advanced Database Features**: Details and code for the 5 advanced objects (Triggers, Stored Procedures, Functions, Views).
13. **12. Testing**: Positive and negative test cases with expected vs actual results and Oracle error code screenshots.
14. **13. Results**: Summary of achievements, query results, database performance.
15. **14. Conclusion & Individual Contributions**: Reflection and percentage contribution breakdown.
